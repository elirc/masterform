1. [01-code-review-mindset.md](01-code-review-mindset.md) — the five review layers + this repo's checklist
2. [02-writing-prs-and-rfcs.md](02-writing-prs-and-rfcs.md) — templates tuned to this repo's CI and norms
3. [03-maintainer-communication.md](03-maintainer-communication.md) — asking, proposing, reporting, disagreeing

These map directly to interview rounds: review katas are code-review rounds; PR/RFC writing is the "collaboration" behavioral evidence; maintainer communication scripts double as conflict/ambiguity STAR material.
