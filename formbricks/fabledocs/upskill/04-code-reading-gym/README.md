# 04 — Code Reading Gym

Active practice. Reading code is a trainable skill with the same structure as reviewing it: inputs → invariants → side effects → failure modes. Do these with the repo open and a scratch file; thinking without writing doesn't count.

1. [01-annotation-drills.md](01-annotation-drills.md) — 10 real excerpts to annotate (≤2 per sitting)
2. [02-trace-tables.md](02-trace-tables.md) — 6 step-by-step traces with value shapes and risks
3. [03-fake-code-contrasts.md](03-fake-code-contrasts.md) — 10 bad-vs-better pairs mapped to real repo patterns
4. [04-review-katas.md](04-review-katas.md) — 9 fake PRs to review with graded findings

Interview relevance: debugging and code-review rounds are literally these drills with a timer. The timed versions live in [08-interview-prep/05](../08-interview-prep/05-debugging-and-code-review-rounds.md).
