# 08 — Interview Prep

Target: **mid-level fullstack JS interviews**, answered with evidence from this codebase instead of memorized trivia. Over 60% of the ~55 question cards here anchor to real Formbricks code — that's deliberate: "for example, in a survey platform I've studied…" followed by a concrete tradeoff is the highest-signal sentence a candidate can say.

## How mid-level loops typically run

1. **Screen** (30-45m): resume walk + one coding/JS-knowledge segment → files 01/02.
2. **Technical deep-dive** (60m): your projects, probed for depth → your module-06 work + STAR file 06.
3. **Practical coding** (60m): build/debug something real → the gym (module 04) + file 05.
4. **System design** (45-60m): → file 04, rehearsed as a walkthrough.
5. **Behavioral** (45m): → file 06 worksheets.

## The golden rule

Every answer = **concrete example + tradeoff + failure mode**. Definition-only answers cap you at junior. The cards enforce this: each shows what junior/mid/senior sound like — the difference is never vocabulary, it's *which risks you volunteer*.
