# Architectural Cartographer

This suite is a top-down map of the Formbricks codebase for a product owner growing into engineering ownership. It starts with the whole system, then narrows into routing, React, API boundaries, authorization, Prisma persistence, testing, debugging, and code review.

Use this order:

1. `00-reading-map.md` to build your first mental model.
2. `01-junior-engineer.md` to learn where things live and how simple files behave.
3. `02-mid-level-engineer.md` to trace the survey list feature across UI, state, API, auth, service, database, and response.
4. `03-senior-engineer.md` to practice critique, risk spotting, test design, performance, and security.
5. `04-reference-suite.md` as a reusable field manual when reviewing or changing the app.

Every codebase claim points to a concrete file and line range. When you see a checkpoint, answer it out loud or in notes, then immediately compare yourself against the self-grading section. Do not treat the rubric as the answer key; treat it as a mirror for what your explanation should contain.
