# Mission Learning Path

This suite is a training campaign. Do not read it like documentation. Open the files, trace the line ranges, annotate the code, answer the checkpoint, and compare your answer to the self-grading rubric.

Pacing:

- Tier 1: do one mission per day until route files, components, types, and simple backend routes feel familiar.
- Tier 2: do two missions per week; these require tracing state, API contracts, middleware, and full-stack behavior.
- Tier 3: do one mission per week; these train senior judgment: architecture decisions, bug prediction, performance, security, tests, and history.

This suite differs from normal docs because every mission asks you to do something: trace, explain, review, debug, or design. Use the exact file and line ranges as your map.
